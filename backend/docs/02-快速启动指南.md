# GitHub Helper 后端 - 快速启动指南

---

## 前置条件

- **Node.js** >= 18（推荐 20+）
- **npm** >= 9
- 已完成 [人工配置文档](./01-人工配置文档.md) 中的所有步骤
- 已创建 `.env` 文件（参考 `.env.example`）

---

## Step 1：安装依赖

```bash
cd code/backend
npm install
```

---

## Step 2：生成 Prisma Client

```bash
npx prisma generate
```

---

## Step 3：数据库迁移

```bash
# 开发环境使用 db push（快速同步 schema 到数据库）
npx prisma db push

# 或者使用正式迁移
npx prisma migrate dev --name init
```

> `db push` 适合开发快速迭代；`migrate dev` 会生成迁移文件，适合团队协作。

---

## Step 4：启动开发服务器

```bash
npm run start:dev
```

服务将在 `http://localhost:3800` 启动。

---

## Step 5：验证服务

```bash
# 检查服务是否启动
curl http://localhost:3800/api/v1/auth/me
# 预期返回 401（未登录）
```

---

## 接口测试流程

### 1. 登录

在浏览器中访问：
```
http://localhost:3800/api/v1/auth/github/login
```
会跳转到 GitHub 授权，授权后回调到 `http://localhost:3000/dashboard`。

> 如果前端尚未启动，回调会 404，但 Cookie 已经设置。  
> 你可以在浏览器开发者工具 → Application → Cookies 中看到 `gh_helper_token`。

### 2. 查看当前用户

```bash
# 使用浏览器（已有 Cookie）直接访问：
http://localhost:3800/api/v1/auth/me
```

### 3. 安装 GitHub App

```bash
# 获取安装链接
GET http://localhost:3800/api/v1/github-app/install-url
```

在浏览器中打开返回的 `installUrl`，安装到目标仓库。

### 4. 导入仓库

```bash
POST http://localhost:3800/api/v1/repos/import
Content-Type: application/json
Cookie: gh_helper_token=<your_token>

{ "repoUrl": "https://github.com/your-user/your-repo" }
```

### 5. 配置翻译

```bash
# 扫描 Markdown 文件
GET http://localhost:3800/api/v1/repos/1/tree

# 保存翻译配置
PUT http://localhost:3800/api/v1/repos/1/config
{ "baseLanguage": "zh-CN", "targetLanguages": ["en", "ja"], "readmeLinksEnabled": true, "runMode": "platform" }

# 保存跟踪文档
PUT http://localhost:3800/api/v1/repos/1/tracked-docs
{ "sourcePaths": ["README.md", "docs/guide.md"] }
```

### 6. 发起翻译

```bash
POST http://localhost:3800/api/v1/repos/1/jobs/translate
{ "mode": "full" }

# 轮询任务状态
GET http://localhost:3800/api/v1/jobs/<jobId>
```

## 常见问题

### Q: 登录回调后前端 404？
A: 前端未启动。Cookie 已设置成功，可通过 `GET /api/v1/auth/me` 验证。

### Q: GitHub API 报 401？
A: 检查 GitHub App 的 Private Key 是否正确配置，注意 `\n` 转义。

### Q: 翻译任务卡在 pending？
A: Worker 每 5 秒轮询一次。检查 `.env` 中的 `OPENROUTER_API_KEY_PLATFORM` 是否有效。

### Q: Webhook 收不到？
A: 本地开发需要 Smee 代理，确保 `smee` 客户端在运行。
