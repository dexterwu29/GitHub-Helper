# GitHub Helper 后端 - 人工配置文档

> 本文档说明需要手动完成的配置步骤，缺一不可。

---

## 1. 创建 Neon PostgreSQL 数据库

1. 访问 [https://neon.tech](https://neon.tech)，注册/登录
2. 创建 Project，选择 **PostgreSQL 16+**，Region 建议 `us-east-2` 或距离你最近的区域
3. 创建完成后，在 Dashboard 获取 **Connection string**，格式如：
   ```
   postgresql://user:password@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require
   ```
4. 将此连接字符串填入 `.env` 文件的 `DATABASE_URL`

---

## 2. 创建 GitHub App

### 2.1 进入创建页

访问：`https://github.com/settings/apps/new`

### 2.2 填写信息

| 字段 | 值 |
|---|---|
| **GitHub App name** | `GitHub-translator-helper-app` |
| **Homepage URL** | `http://localhost:3800` |
| **Callback URL** | `http://localhost:3800/api/v1/auth/github/callback` |
| **Webhook URL** | `http://localhost:3800/api/v1/webhooks/github`（开发环境需用 Smee 代理，见下文） |
| **Webhook secret** | 自定义一个随机字符串，记下来填入 `.env` 的 `GITHUB_WEBHOOK_SECRET` |

### 2.3 设置权限（Permissions）

| 权限 | 级别 |
|---|---|
| **Contents** | Read & Write |
| **Pull requests** | Read & Write |
| **Metadata** | Read |

### 2.4 订阅事件（Subscribe to events）

勾选：
- [x] **Push**

### 2.5 安装范围

选择 **Only on this account**（MVP 阶段）

### 2.6 创建后获取信息

创建完成后，在 App 设置页获取：

| 信息 | 对应 `.env` 变量 |
|---|---|
| App ID（顶部显示） | `GITHUB_APP_ID` |
| Client ID | `GITHUB_APP_CLIENT_ID` |
| Client Secret（需生成） | `GITHUB_APP_CLIENT_SECRET` |
| Private Key（需下载 `.pem`） | `GITHUB_APP_PRIVATE_KEY` |

### 2.7 Private Key 处理

下载的 `.pem` 文件内容，需要将换行替换为 `\n`，放入 `.env`：

```bash
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEp...\n-----END RSA PRIVATE KEY-----"
```

**快捷处理方式**（bash / PowerShell）：
```bash
# bash / Git Bash
awk 'NF {sub(/\r/, ""); printf "%s\\n",$0;}' your-app-name.pem
```

## 3. 配置 OpenRouter

1. 访问 [https://openrouter.ai](https://openrouter.ai)，注册/登录
2. 进入 [API Keys](https://openrouter.ai/settings/keys) 页面
3. 创建一个 API Key
4. 将 Key 填入 `.env` 的 `OPENROUTER_API_KEY_PLATFORM`
5. 默认模型为 `google/gemini-2.0-flash-001`，可在 `.env` 中修改 `OPENROUTER_DEFAULT_MODEL`

---

## 4. 生成加密密钥

`ENCRYPTION_KEY` 用于 AES-256-GCM 加密用户的 API Key，需要 32 字节（64 位十六进制字符串）。

生成方式：

```bash
# Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 或 PowerShell
[System.Convert]::ToHexString([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32)).ToLower()
```

---

## 5. 生成 JWT Secret

`JWT_SECRET` 可以用任意随机字符串：

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 6. 本地 Webhook 开发（Smee 代理）

GitHub Webhook 无法直接发送到 `localhost`，需使用 Smee 代理。

### 6.1 安装 Smee

```bash
npm install -g smee-client
```

### 6.2 创建通道

访问 [https://smee.io/new](https://smee.io/new)，获得一个 URL（如 `https://smee.io/xxxxxx`）

### 6.3 在 GitHub App 设置中

将 Webhook URL 改为你的 Smee URL

### 6.4 启动 Smee 客户端

```bash
smee -u https://smee.io/xxxxxx -t http://localhost:3800/api/v1/webhooks/github
```

### 6.5 安装 GitHub App

访问 `https://github.com/apps/GitHub-translator-helper-app/installations/new`，将 App 安装到你的测试仓库。

## 7. 完整 .env 文件示例

```env
APP_ENV=local
APP_PORT=3800
APP_BASE_URL=http://localhost:3800
FRONTEND_URL=http://localhost:3000

JWT_SECRET=<你生成的随机字符串>

DATABASE_URL=postgresql://<user>:<password>@<host>/github_helper?sslmode=require

GITHUB_APP_ID=<App ID>
GITHUB_APP_CLIENT_ID=<Client ID>
GITHUB_APP_CLIENT_SECRET=<Client Secret>
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n...\n-----END RSA PRIVATE KEY-----"
GITHUB_WEBHOOK_SECRET=<Webhook Secret>

OPENROUTER_API_KEY_PLATFORM=<OpenRouter API Key>
OPENROUTER_DEFAULT_MODEL=google/gemini-2.0-flash-001

ENCRYPTION_KEY=<64位十六进制字符串>
```
