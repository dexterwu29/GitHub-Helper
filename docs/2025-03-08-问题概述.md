## 二、问题详情与解决方案

### 2.1 Hydration 错误：`<a>` 不能嵌套 `<a>`

**现象：**
- 控制台报错：`In HTML, <a> cannot be a descendant of <a>. This will cause a hydration error.`
- 位置：`RepoCard` 组件（`src/app/dashboard/page.tsx`）

**原因：**
- 整个卡片被 `<Link>`（渲染为 `<a>`）包裹
- 内部又有一个指向 GitHub 的 `<a href="https://github.com/...">`
- HTML 规范不允许锚点嵌套

**解决方案：**
将内部的 GitHub 链接从 `<a>` 改为 `<span>`，通过 `onClick` 打开新标签页：

```tsx
<span
  role="link"
  tabIndex={0}
  className="text-surface-400 hover:text-brand-500 cursor-pointer inline-flex"
  onClick={(e) => {
    e.preventDefault()
    e.stopPropagation()
    window.open(githubUrl, '_blank', 'noopener,noreferrer')
  }}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault()
      window.open(githubUrl, '_blank', 'noopener,noreferrer')
    }
  }}
>
  <ExternalLink className="w-3.5 h-3.5" />
</span>
```

保留 `role="link"`、`tabIndex={0}`、`onKeyDown` 以支持无障碍和键盘操作。

### 2.2 PUT /api/v1/repos/[repoId]/tracked-docs 返回 500

**现象：**
- 点击「立即处理排队任务」或保存配置时，`saveTrackedDocs` 请求返回 500

**可能原因：**
- `filePaths` 数组存在重复，违反 `@@unique([repoId, sourcePath])` 约束
- 请求体解析或 Prisma 操作抛出未捕获异常

**解决方案：**
1. 添加 try-catch 捕获并记录错误
2. 对 `filePaths` 去重并过滤无效值：

```ts
const uniquePaths = [...new Set(filePaths)].filter(
  (fp): fp is string => typeof fp === 'string' && fp.length > 0
)
```

3. 返回 JSON 格式的 500 响应，便于前端解析

---

### 2.3 GET /api/v1/jobs/[jobId] 返回 500

**现象：**
- 轮询任务状态时 `jobsApi.get(jobId)` 返回 500
- 控制台出现 `Uncaught SyntaxError: Unexpected identifier 'server'`（因服务端返回 HTML 错误页，客户端 `res.json()` 解析失败）

**可能原因：**
- 服务端未捕获异常，返回 Next.js 默认 HTML 错误页
- `jobId` 非法导致 `BigInt()` 抛出

**解决方案：**
1. 在 jobs 路由添加 try-catch，返回 JSON 格式 500
2. 对 `jobId` 做 BigInt 转换校验，非法时返回 404
3. 在 `api.ts` 的 `request` 中捕获 `res.json()` 失败，抛出友好错误：

```ts
try {
  json = await res.json()
} catch {
  throw new ApiError('PARSE_ERROR', res.status >= 500 ? '服务异常' : '响应解析失败', res.status)
}
```

## 三、调试建议

1. **服务端日志**：所有 API 路由已添加 `console.error('[route-name]', err)`，出错时在 dev server 终端查看
2. **客户端**：`ApiError` 会携带 `message` 和 `status`，便于定位
3. **Prisma BigInt**：返回给前端的 BigInt 需显式 `.toString()`，或在 `prisma.ts` 中扩展 `BigInt.prototype.toJSON`
